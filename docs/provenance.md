# Provenance

This repository was reconstructed in 2026 from artifacts preserved from a 2025 Unity / ML-Agents study.

## Included

- `preserved/BasicController.cs` — recovered from the 2025 archive.
- `preserved/MyAgent.cs` — recovered from the 2025 archive.
- `examples/bug_report_sample.json` — condensed from a preserved JSON run report dated 2025-02-24.
- `docs/evidence.md` — inventory of preserved experiment videos and the claims they support.
- `docs/historical_commands.md` — reconstructed from the preserved command note.

## Preserved Outside This Public Repository

- Experiment videos showing Unity and the ML-Agents trainer running together.
- Extracted screenshots from those videos.
- Large raw JSON logs containing highly repetitive warning entries.
- A recovered text copy of a modified `UnityPGTA.cs` whose exact final execution status cannot be established.

## Not Recovered as a Complete Project

- A complete Unity project root with the final scene, `Packages`, and `ProjectSettings`.
- `collision.cs`, which is referenced by preserved run logs but was not recovered.

## Upstream

The reproduction study was based on the public repository:

https://github.com/amkorousagi/UnityPGTA

The upstream source tree is not redistributed here. This repository should be read as a **reproduction-study portfolio artifact**, not as a fork or replacement for the upstream project.
