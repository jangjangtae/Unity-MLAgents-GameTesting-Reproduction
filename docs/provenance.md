# Provenance

This repository was reconstructed in 2026 from artifacts preserved from a 2025 Unity / ML-Agents study.

## Included

- `preserved/BasicController.cs` — recovered from the user's 2025 archive.
- `preserved/MyAgent.cs` — recovered from the user's 2025 archive.
- `examples/bug_report_sample.json` — condensed from a preserved JSON run report dated 2025-02-24.
- `docs/images/*.png` — frames extracted from preserved experiment videos.
- `docs/historical_commands.md` — reconstructed from the preserved command note.

## Not Included

- The upstream UnityPGTA source tree.
- The recovered modified copy of `UnityPGTA.cs`, because its exact final execution status cannot be established and it derives from upstream code.
- A full Unity project/scene, because the historical project root was not preserved completely.
- `collision.cs`, which is referenced by preserved run logs but was not recovered.

## Upstream

The reproduction study was based on the public repository:

https://github.com/amkorousagi/UnityPGTA

This repository should be read as a **reproduction-study portfolio artifact**, not as a fork or replacement for the upstream project.
